# EuRoC 全套结果汇总（最终三表）



## 口径说明

- 统一约定：`B` = Baseline = Passive LTV（不向优化器加入 LTV factor）。
- `Δ = (Method - B) / B × 100%`，因此 **Δ < 0 表示改善，Δ > 0 表示退化**。
- `G_gate`：Stage 4 的 Gravity Quality Gate 单因子结果。
- `V_fixed`：Stage 5 的固定 Velocity factor 单因子结果。
- `G_gate + V_fixed`：Stage 6 联合结构结果。
- `G_gate + V_gate`：Stage 6b 在线 Heuristic Velocity Gate 结果；Rotation 已按 Stage 6c 的**共同 B 对齐**复评。
- Stage 4 / Stage 5 / Stage 6 属于不同阶段的 frozen pipeline。各自的 `Δ` 都是相对该阶段的 Baseline/Passive 计算，适合作为方法演进与消融背景；`G_gate + V_gate` 是当前最新在线固定规则结构。
- **Rotation 注意：** Stage 6c 已证明“每个运行独立做位置刚体对齐”会污染姿态比较。因此 `G_gate + V_gate` 的 Rotation 是当前修正后的正式值；`G_gate`、`V_fixed`、`G_gate + V_fixed` 的历史 Rotation 在论文最终定稿前最好统一按共同 B 对齐重算。
- Stage 4 没有完整记录 `G_gate` 的 Velocity RMSE，因此 Velocity 表不放 `G_gate` 单独列。

## 当前最终固定规则结构的直接结论

当前最新在线固定规则结构为：`B + G_gate + V_gate`。

- ATE 在 V2_01、V2_02、V2_03 等序列上有明显改善；
- Velocity RMSE 在 V2_02、V2_03 上改善明显；
- Rotation 大多数序列变化较小或改善，但 `V1_02_medium` 出现 **+12.76%** 的明显退化，是当前最清晰的 failure case；
- 因此固定规则 Gate 已表现出总体收益，但仍存在场景依赖性，后续可作为 `B + G_gate + V_RL` 的基线。
